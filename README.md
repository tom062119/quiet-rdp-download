### 如何使用

1. 先退出旧版 Quiet RDP，再用 Tails 浏览器下载 `Quiet-RDP-Tails-amd64.run`。
2. 在文件管理器中右键该文件 → **属性 → 权限 → 允许作为程序执行**。
3. **双击打开**。安装器显示进度、加入应用菜单并自动打开软件。
4. 等 Tor 连接完成，登录管理员分配的账号，再双击服务器名称连接。

不需要输入命令或管理员密码，不需要另装 Remmina、torsocks 或 RDP 插件。下载位置禁止执行时，可用文件管理器把文件移到个人文件夹后打开。

程序只安装到本次开机的内存目录。**不提供持久化安装；重启 Tails 后重新下载。** 安装过程不联网；登录、同步和远程连接需要网络。账号由管理员创建，不开放注册。

### 0.4.1 更新

- **输入法**：新增 Rime 五笔拼音混输、五笔 86、简体拼音，保留极点和海峰五笔。输入法和截图开关改为主窗口中的工具卡片。
- **截图**：全屏定格后直接框选、标注，加入放大镜、取色、直线、荧光笔、序号和贴图；二维码与中英文文字识别按需在本机执行。
- **连接**：新增自动、H.264、RemoteFX 编码选择，显示服务器报告的延迟和带宽；调整 Onion、慢速链路的编码协商及有保活时的卡死恢复。远程窗口和全屏栏增加最小化按钮。
- **后台**：增强按用户管理服务器和快捷入口授权，增加账号删除及生成一次性 Onion 安装命令。Windows 服务只会在管理员自行执行命令后改变。
- **安装包**：移除 Telegram 下载功能，复用 Tails 已有 GTK 库，安装器载荷改为 xz 压缩。安装时保留 Rime 词典的原始文件时间。

**RDP 证书行为有变化：未知证书和变化的证书会自动接受，不再弹出指纹确认；“连接信息”显示是否验证。Tor 公网线路因此缺少可靠的 RDP 服务器证书身份核对，存在出口冒充服务器的风险。登录和同步 API 的 HTTPS 证书校验保持开启。**

后台提供的单跳 Onion 选项不隐藏服务器网络位置；用户一侧仍走 Tor。实际速度取决于线路和服务器，本版没有验证提速幅度。发布安装入口不会自动改造现有服务器。

**本次完成编译、打包和文件完整性核对，没有执行完整功能测试、真实 Tails 安装或 Windows 连接验收。** Rime、截图与识别、编码协商以及单跳 Onion 安装仍需在对应环境验证。保险箱和验证码功能还处于设计阶段，不包含在 0.4.1 中。
