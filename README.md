# Quiet RDP · Tails 单文件便携版

适用于 **Tails 7 / amd64（64 位 Intel、AMD 电脑）**。**压缩包内只有一个 `Quiet-RDP` 文件，解压后双击运行。**

## [下载 Quiet RDP 0.6.1](https://github.com/tom062119/quiet-rdp-download/releases/latest/download/Quiet-RDP-Tails-amd64.tar.xz)

[打开最新版发布页](https://github.com/tom062119/quiet-rdp-download/releases/latest)

压缩包 **28.82 MB（27.49 MiB）**；解压后的唯一文件 **`Quiet-RDP` 约 28.84 MB**。

### 打开方法

1. 退出旧版，下载 **`Quiet-RDP-Tails-amd64.tar.xz`**。
2. 右键压缩包 → **解压到…**，选择 Tails 的非持久化个人文件夹。
3. 双击解压得到的 **`Quiet-RDP`**，等 Tor 就绪后登录使用。

解压后只需要这个文件，可以单独移动；没有需要一起携带的 `bin`、`lib` 文件夹。部分解压工具会自动创建一层文件夹，里面仍只有 `Quiet-RDP`。请先解压，不要从压缩包预览中运行。

无需安装、终端命令、管理员密码或 FUSE。`Quiet-RDP` 是原生程序，压缩包保存了 `0755` 执行权限；解压工具与目录的权限限制仍由系统控制，真实 Tails 文件管理器双击流程尚待用户实测。如果所在目录禁止执行，把这个文件移到 Tails 的个人文件夹。

双击后自动在私有内存目录准备运行组件。正常退出后清理未使用的组件；如果系统输入法仍引用这些文件，会保留在内存中供它继续使用，重启 Tails 后清除。同一构建在当前会话中可复用这些组件，不需要重新下载依赖。程序不自动添加应用菜单。每次重启 Tails 后重新下载主压缩包即可。

展开与启动准备不联网；登录、同步、翻译和远程连接需要网络。0.6.1 只调整交付和启动方式，客户端业务功能、后台和 API 与 0.6.0 一致。

### 已有功能

- 组织管理与授权：管理员按用户或组织分配服务器及 Onion 权限。
- 保险箱和验证码：独立密码、TOTP、便签、主动扫码，以及用户选择的组织共享。
- 工具页：输入法、截图、翻译和加密的账号偏好同步。
- 翻译：主动提交的文字经 Tor 发往 Cloudflare 模型处理，属于在线功能。应用不保存翻译历史，不能据此承诺服务平台完全不留数据。

组织成员可以查看、修改和删除共享内容；移出组织不能收回已经看到的内容，本版不会自动轮换组织密钥。保险箱密码无法找回，连续输错 20 次会清空保险箱，应用不提供恢复功能。

RDP 自动接受未知或变化证书的行为沿用上一版，Tor 公网线路的服务器身份核验因此减弱。登录和同步 API 的 HTTPS 证书校验保持开启。

**已完成编译、单文件归档结构和哈希核对；没有运行完整功能测试、真实 Tails 双击、运行目录清理、输入法生命周期或 Windows RDP 验收。** 当前版本供用户实测。
