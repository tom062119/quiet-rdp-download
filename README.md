# Quiet RDP · Tails 单文件便携版

适用于 **Tails 7 / amd64（64 位 Intel、AMD 电脑）**。**压缩包内只有一个 `Quiet-RDP` 文件，解压后双击运行。**

## [下载 Quiet RDP 0.6.4](https://github.com/tom062119/quiet-rdp-download/releases/latest/download/Quiet-RDP-Tails-amd64.tar.xz)

压缩包大小：**28.1 MB**（28,093,576 字节）。[打开最新版发布页](https://github.com/tom062119/quiet-rdp-download/releases/latest)

### 打开方法

1. 退出旧版，下载 **`Quiet-RDP-Tails-amd64.tar.xz`**。
2. 右键压缩包 → **解压到…**，选择 Tails 的非持久化个人文件夹。
3. 双击解压得到的 **`Quiet-RDP`**，等 Tor 就绪后登录使用。

请先解压，不要从压缩包预览中运行。部分解压工具会创建一层文件夹，里面仍只有这个程序。无需安装、终端命令、管理员密码或 FUSE；归档保留执行权限。目录和解压工具的执行权限仍由系统控制，真实 Tails 文件管理器流程需实测。

运行组件自动展开到私有内存目录，退出后清理未使用的组件；输入法仍引用的组件保留至不再使用或重启。不注册系统应用菜单、不做持久化安装，每次重启 Tails 后重新下载即可。登录、同步、翻译、远程连接及新版更新检查需要网络。

### 0.6.4 更新

- 登录后可自行修改登录密码：输入现在的密码和新密码，当前电脑保持登录，其他登录会退出。保险箱密码独立，不受影响。
- 截图和 PNG 图片剪贴板改为后台解码，截图选框、放大镜和画笔只重绘变化部分，减少大屏操作卡顿。
- GNOME 自动复制的整屏截图不再自动转发到远程桌面；主动复制的选区仍可以直接粘贴。图片改用 24 位 DIB，降低同尺寸图片的传输量。
- 截图支持选框微调、颜色复制和贴图滚轮缩放。
- 优化单文件压缩布局；保留签名自动更新、中文输入、双向剪贴板、分辨率适配及断线重连。

0.6.3 起可经 Tor 检查并下载新版，校验 Ed25519 签名、文件大小与 SHA-256 后准备替换，点“重启更新”或下次打开生效。更早版本需先手动下载一次。发布附件中的裸程序和签名清单供更新机制使用，日常下载仍选压缩包。

### 账号与隐私

账号由管理员创建，不开放注册。正常在线通过现有目录同步续期，不重复传输登录密码；令牌只在内存盘保存，退出登录撤销，重启 Tails 清除。自助修改密码保留当前登录并撤销其他登录；管理员停用、重设密码和撤权仍有效。授权同步连续失败超过 180 秒会停止旧授权。

API 接受普通网络和 Tor 的合法原生请求，要求 TLS 1.3、登录、请求签名与防重放；Tails 客户端仍通过本机 Tor / Onion。同一 IP 在 15 分钟内累计 5 次密码验证失败，临时封禁登录 15 分钟，已有会话不受影响；只存带密钥的 IP 哈希和到期计数，不新增明文 IP 或登录历史。

提供按用户或组织分配的服务器及 Onion 权限、保险箱、TOTP、便签、主动扫码、共享内容、输入法、截图及在线翻译。翻译文字经 Tor 发往 Cloudflare 模型；组织成员可查看、修改和删除共享内容，移出组织不能收回已看到的内容。保险箱密码无法找回，连续输错 20 次会清空保险箱。

RDP 自动接受未知或变化证书的行为沿用上一版，公网线路的目标身份核验因此减弱；API 的 HTTPS 证书校验保持开启。不能承诺 Cloudflare、Windows 等第三方平台完全不留记录。
