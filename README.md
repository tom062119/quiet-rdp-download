### 如何使用

1. 退出旧版 Quiet RDP，用 Tails 浏览器下载 `Quiet-RDP-Tails-amd64.run`。
2. 在文件管理器中右键该文件 → **属性 → 权限 → 允许作为程序执行**。
3. **双击打开**。安装器显示进度、加入应用菜单并自动打开软件。
4. 等 Tor 连接完成，登录管理员分配的账号，再双击服务器名称连接。

不需要输入命令或管理员密码，不需要另装 Remmina、torsocks 或 RDP 插件。下载位置禁止执行时，可用文件管理器把文件移到个人文件夹后打开。

程序只安装到本次开机的内存目录。**不提供持久化安装；重启 Tails 后重新下载。** 安装过程不联网；登录、同步和远程连接需要网络。账号由管理员创建，不开放注册。

### 0.5.0 更新

- **保险箱**：保存账号密码和便签，使用独立的保险箱密码。客户端采用 Argon2id、HKDF 与 AES-256-GCM，云端保存加密记录；解密内容只在运行期间保留于内存。支持搜索、编辑、随机密码、改密码、手动刷新和自动锁定。
- **两步验证码**：账号条目可附带 TOTP，在验证码页显示倒计时和下一组验证码。支持手动密钥、otpauth 链接、剪贴板二维码及 Google 身份验证器迁移格式；按按钮后才截图识别二维码。
- **剪贴板**：复制的密码和验证码可同步到当前远程桌面；30 秒后，在剪贴板内容仍是该值时清除。
- **主窗口**：顶部增加服务器、保险箱、验证码三个页签。Tor / Onion 入口改为每台服务器单独选择；输入法和画面选项移到各远程窗口菜单。
- **后台**：增加保险箱条数、占用空间及错误次数显示，可清空保险箱；配套云端接口与数据库迁移已部署。

**保险箱密码无法找回，连续输错 20 次会自动清空该账号的保险箱；应用不提供数据恢复功能。** 管理员主动清空或删除账号也会删除相应保险箱。请使用独立的强密码。该规则不等于防止数据库被取得后的离线猜测；这次发布没有进行独立密码学审计或真实环境安全验收。

沿用上一版的 RDP 证书行为：未知或变化的证书自动接受，不再弹出指纹确认；“连接信息”显示验证状态。Tor 公网线路因此缺少可靠的 RDP 服务器证书身份核验。登录和同步 API 的 HTTPS 证书校验保持开启。

**本次完成编译、打包和文件完整性核对，没有运行完整功能测试、真实 Tails 安装、Windows RDP 连接或保险箱端到端验收。** 当前是供用户实测的试用包。

Quiet RDP 自有代码使用 [二进制分发许可](LICENSE)。本仓库不发布客户端源码包、后端代码、账号数据或密钥。安装器包含运行所需的桌面助手、第三方组件及各自许可。

发布页的 `SHA256SUMS` 用于核对文件完整性。程序已去除调试符号，不能据此承诺无法逆向分析。本项目与 Tails 官方没有隶属关系，尚未加入 Tails/Debian 官方 APT 仓库。
