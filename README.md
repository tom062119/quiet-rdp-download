# Quiet RDP · Tails 单文件便携版

适用于 **Tails 7 / amd64（64 位 Intel、AMD 电脑）**。**压缩包内只有一个 `Quiet-RDP` 文件，解压后双击运行。**

压缩包大小：**28.8 MB**（28,832,860 字节）。

[打开最新版发布页](https://github.com/tom062119/quiet-rdp-download/releases/latest)

### 打开方法

1. 退出旧版，下载 **`Quiet-RDP-Tails-amd64.tar.xz`**。
2. 右键压缩包 → **解压到…**，选择 Tails 的非持久化个人文件夹。
3. 双击解压得到的 **`Quiet-RDP`**，等 Tor 就绪后登录使用。

请先解压，不要从压缩包预览中运行。部分解压工具会创建一层文件夹，里面仍只有这个程序。无需安装、终端命令、管理员密码或 FUSE；归档保留 `0755` 执行权限。目录和解压工具的执行权限仍由系统控制，真实 Tails 文件管理器流程需实测。

运行组件自动展开到私有内存目录，退出后清理未使用的组件；输入法仍引用的组件保留至不再使用或重启。不注册系统应用菜单、不做持久化安装，每次重启 Tails 后重新下载即可。登录、同步、翻译、远程连接及新版更新检查需要网络。

### 账号和隐私

正常在线通过现有目录同步续期，不重复传输登录密码。内存盘保存可撤销的令牌，不保存邮箱和登录密码；退出登录立即撤销，重启 Tails 清除。管理员停用、改密码和撤权仍有效，授权同步连续失败超过 180 秒会停止旧授权。

API 接受普通网络和 Tor 的合法原生请求，Tails 客户端仍通过本机 Tor / Onion。API 继续要求 TLS 1.3、登录、签名和防重放。

同一 IP 在 15 分钟内累计 5 次密码验证失败，临时封禁登录 15 分钟；挑战、登录和同账号另有限速。已有会话不受临时封禁影响。只存带密钥的 IP 哈希和到期计数，不新增明文 IP 或登录历史。

### 已有功能与边界

管理员按用户或组织分配服务器和 Onion 权限；提供保险箱、TOTP、便签、主动扫码、共享内容、输入法、截图及在线翻译。翻译文字经 Tor 发往 Cloudflare 模型，应用不保存翻译历史；不能据此承诺平台完全不留数据。

组织成员可查看、修改和删除共享内容，移出组织不能收回已看到的内容。保险箱密码无法找回，连续输错 20 次会清空保险箱。RDP 自动接受未知或变化证书的行为沿用上一版，公网线路的目标身份核验因此减弱；API 的 HTTPS 证书校验保持开启。

真实 Tails、Windows RDP 性能及从未来版本端到端更新仍需用户实测。验证结果见发布页。
