# Quiet RDP · Tails 单文件便携版

适用于 **Tails 7 / amd64（64 位 Intel、AMD 电脑）**。**压缩包内只有一个 `Quiet-RDP` 文件，解压后双击运行。**

## [下载 Quiet RDP 0.6.2](https://github.com/tom062119/quiet-rdp-download/releases/latest/download/Quiet-RDP-Tails-amd64.tar.xz)

[打开最新版发布页](https://github.com/tom062119/quiet-rdp-download/releases/latest)

压缩包 **28.81 MB**；解压后的唯一文件约 **28.83 MB**。

### 打开方法

1. 退出旧版，下载 **`Quiet-RDP-Tails-amd64.tar.xz`**。
2. 右键压缩包 → **解压到…**，选择 Tails 的非持久化个人文件夹。
3. 双击解压得到的 **`Quiet-RDP`**，等 Tor 就绪后登录使用。

解压后可以单独移动这个文件。部分解压工具会自动创建一层文件夹，里面仍只有 `Quiet-RDP`。请先解压，不要从压缩包预览中运行。

无需安装、终端命令、管理员密码或 FUSE。压缩包保存了原生程序的 `0755` 执行权限；解压工具与目录的权限限制仍由系统控制。若所在目录禁止执行，请移到 Tails 的个人文件夹。真实 Tails 文件管理器双击流程仍需用户实测。

程序自动在私有内存目录准备运行组件。退出后清理未使用的组件；系统输入法仍引用的组件保留至不再使用或 Tails 重启。程序不自动注册应用菜单，不持久化安装。每次重启 Tails 后重新下载主压缩包即可。

展开和启动准备不联网；登录、同步、翻译和远程连接需要网络。

### 0.6.2 更新

- **长期在线自动续期**：修复约 12 小时后自动回到登录页的问题；通过现有同步续期，不增加请求、不重复传输密码。关闭应用后凭证到期仍需重新登录。
- **取消 API 的 Tor 出口分类限制**：普通网络与 Tor 都可提交合法原生请求；当前 Tails 客户端继续通过本机 Tor 连接。
- **登录防暴力尝试**：同一 IP 在 15 分钟内累计 5 次密码验证失败，临时封禁登录 15 分钟；挑战和登录请求另有限速，原有账号限速继续保留。已有会话不受该临时封禁影响。
- **隐私**：只保存带密钥的 IP 哈希和到期计数，不新增明文 IP 或登录历史。令牌仍只写入当前 Tails 内存盘，不保存邮箱或登录密码；退出登录即撤销。

管理员停用账号、改密码或撤销服务器权限仍会生效。授权同步连续失败超过 180 秒会停止旧授权。Tor 和目标服务器的网络故障也可能导致远程桌面断开。

### 已有功能

- 管理员按用户或组织分配服务器及 Onion 权限。
- 保险箱、TOTP、便签、主动扫码和组织共享。
- 输入法、截图、在线翻译及加密的账号偏好同步。

翻译文字经 Tor 发往 Cloudflare 模型处理；应用不保存翻译历史，不能据此承诺平台完全不留数据。组织成员可查看、修改和删除共享内容；移出组织不能收回已看到的内容，本版不自动轮换组织密钥。保险箱密码无法找回，连续输错 20 次会清空保险箱。

RDP 自动接受未知或变化证书的行为沿用上一版，Tor 公网线路的服务器身份核验因此减弱。登录和同步 API 的 HTTPS 证书校验保持开启。

**验证范围**：63 项云端回归、本地 workerd / D1、Linux 客户端核心回归、单文件结构与哈希、公开下载检查。七天在线续期使用模拟时间验证，没有声称完成真实七天连接测试。真实 Tails、完整 GUI、输入法生命周期和 Windows RDP 验收仍需用户实测。
