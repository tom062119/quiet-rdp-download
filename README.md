# Quiet RDP · Tails 便携版

适用于 **Tails 7 / amd64（64 位 Intel、AMD 电脑）**。0.6.0 改为便携压缩包，解压后双击运行。

## [下载 Quiet RDP 0.6.0 压缩包](https://github.com/tom062119/quiet-rdp-download/releases/latest/download/Quiet-RDP-Tails-amd64.tar.xz)

[打开最新版发布页](https://github.com/tom062119/quiet-rdp-download/releases/latest)

主压缩包 **28.80 MB（27.47 MiB）**，解压后文件合计约 **96.94 MB**。

### 打开方法

1. 退出旧版，下载 **`Quiet-RDP-Tails-amd64.tar.xz`**。
2. 右键压缩包 → **解压到…**，选择 Tails 的个人文件夹。
3. 打开解压得到的 `quiet-rdp-0.6.0-tails7-amd64` 文件夹。
4. 双击里面的 **`Quiet-RDP`**，等 Tor 就绪后登录使用。

无需安装、终端命令或管理员密码。`Quiet-RDP` 是原生启动程序，压缩包内执行权限为 `0755`。正常解压到支持 Unix 权限的目录后，应能保留执行权限，减少另行授权的步骤；真实 Tails 文件管理器的双击过程尚未验收。

**先完整解压，再打开程序。** 不要在压缩包预览中运行，不要只拖出 `Quiet-RDP`：同目录的 `bin`、`lib` 等内容都需要保留。如果下载位置或 U 盘禁止执行，将整个文件夹移到 Tails 的个人文件夹；系统的执行限制不能靠换压缩格式绕过。

便携版不安装软件、不自动添加应用菜单。请在非持久化个人文件夹使用，**每次重启 Tails 后重新下载、解压**。解压不联网，登录、同步、翻译和远程连接需要网络。正常用户只需要下载上面的压缩包。

### 本版更新

- **组织管理与共享**：管理员可把账号加入组织，按组织分配服务器和 Onion 权限；用户可主动把保险箱中的账号或便签分享给组织。
- **工具页**：输入法、截图和翻译集中到独立页签，工具偏好加密保存在账号下，登录后恢复；截图快捷键可调整。
- **翻译**：支持文字、剪贴板和截图 OCR 后翻译。只有主动提交时，文字才经 Tor 发送到 Cloudflare 模型处理；它不是离线功能。应用不保存翻译历史，不能因此承诺服务平台完全不留数据。
- **验证码与保险箱**：调整卡片、排序、密钥复制和组织共享操作，保留独立密码与自动锁定。
- **交付方式**：公开文件改为 `.tar.xz`，包含可双击的原生启动入口；不再把 `.run` 安装器作为公开下载。

组织成员可以查看、修改和删除共享内容；移出组织不能收回已经看到的内容，本版不会自动轮换组织密钥。保险箱密码无法找回，连续输错 20 次会清空保险箱，应用不提供恢复功能。请使用独立的强密码。

RDP 证书行为沿用上一版：未知或变化的证书自动接受，Tor 公网线路的服务器证书身份核验因此减弱；登录和同步 API 的 HTTPS 证书校验保持开启。

**已完成编译、归档内容和哈希核对；没有运行完整功能测试、真实 Tails 解压双击、Windows RDP、组织共享或实际翻译验收。** 当前版本供用户实测。
